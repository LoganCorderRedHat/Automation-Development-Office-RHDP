== Log in to OpenShift

. Open the link:{openshift_console_url}[OpenShift console,window=_blank] and log in as `{openshift_cluster_admin_username}` with password `{openshift_cluster_admin_password}`.

== Get an API token for Preflight

ADO needs an OpenShift API token to configure your cluster.

. In the OpenShift console, open the user menu (your user name, top right) and click *Copy login command*.
. Log in again if asked, then click *Display Token*.
. Copy the value after *Your API token is* (it starts with `sha256~`). You paste it into Preflight in the next section.

NOTE: In a real environment you would use a cluster-admin service account token, as Preflight's help text suggests. Your login token is fine for this workshop.

== Look at the empty bootstrap repository

. Open link:{gitea_url}[Gitea,window=_blank] and sign in as `{gitea_user}` with password `{gitea_password}`.
. Open the `ado-bootstrap` repository. It has a single first commit and a README. ADO fills it in the next sections.
