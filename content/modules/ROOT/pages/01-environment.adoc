== Log in to OpenShift

. Open the link:{openshift_console_url}[OpenShift console,window=_blank] and log in with the admin user from your RHDP order page.

== Get an API token for Preflight

ADO needs an OpenShift API token to configure your cluster.

. Open the *Terminal* tab on the right of this guide (or the web terminal in the OpenShift console).
. Print your token:
+
[source,bash]
----
oc whoami -t
----
. Copy the token. You paste it into Preflight in the next section.

NOTE: In a real environment you would use a cluster-admin service account token, as Preflight's help text suggests. Your login token is fine for this workshop.
