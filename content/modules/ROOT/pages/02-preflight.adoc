:navtitle: 2. Fill out ADO Preflight
include::partial$seat.adoc[]

Open link:{preflight_url}[ADO Preflight,window=_blank].

On the left, under *Build Your Automation*, Preflight lists six steps. The next six pages of this guide match them, in the same order:

[cols="1,3"]
|===
|Preflight step |What you do there

|1. Environment & Platform Selection
|Name the environment, pick *Not using AAP*, choose OpenShift, and set a vault password

|2. Git configuration
|Point Preflight at your Gitea repository

|3. Platform Configuration
|Connect Preflight to your cluster's API

|4. Components & Profiles
|Pick what to build: HTPasswd login, console banner, ACM, OpenShift Virtualization, and MTV

|5. Review & Validate
|Check your answers

|6. Bootstrap Execution
|Generate the automation and push it to Git
|===

Fill out each step, then click *Next* at the bottom right. When a step is complete, its number in the left sidebar turns into a green check mark. You can click any step in the sidebar to go back to it.

The sidebar also lists *Install*, *Configure & Tools*, and *Onboarding* actions. You do not need them in this workshop.
