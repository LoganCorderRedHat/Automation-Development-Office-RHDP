With *Not using AAP*, Preflight can run the generated playbooks itself.

== Preview, then run

. Open *Run generated playbooks (no AAP)*. It opens on its own if you checked that option in step 4.
. Review the list of steps. Each step has *Options* for per-playbook settings.
. Click *Preview commands* to see the exact `ansible-playbook` commands Preflight will run.
. Click *Run selected playbooks* and watch the log.

== Check the results

*Console banner*

. Refresh the link:{openshift_console_url}[OpenShift console,window=_blank]. Your banner text is at the top.

*OpenShift Compliance Operator*

. In the console, open *Operators → Installed Operators* and select project `openshift-compliance`. The Compliance Operator shows *Succeeded*.

You configured your cluster from answers in a form, with every change kept as code in Git.
