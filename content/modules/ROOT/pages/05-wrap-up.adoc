In this workshop you:

* Filled out ADO Preflight for your cluster, one step at a time.
* Ran *Bootstrap*, which generated a Git repository of playbooks, variables, and encrypted vault files and pushed it to Gitea.
* Ran those playbooks from the Preflight container to add an HTPasswd login and a console banner, and to install ACM, OpenShift Virtualization, and MTV.

== Try it yourself

* *Run one playbook again.* In *Generated Playbooks*, leave only the console banner playbook checked and click *Run Playbooks Again*. ADO's playbooks are safe to re-run.
* *Change an answer.* In Step 4, change the *Console Banner Text* and set *Banner action* to *Update (replace all ADO banners)*. In Step 2, under *Advanced Git Settings*, check *Replace existing environment variables*. Run Bootstrap again and look at the new commit in Gitea: your change is recorded in Git. Then run only the console banner playbook.
