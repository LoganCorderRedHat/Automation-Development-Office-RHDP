= Wrap-up
:navtitle: 5. Wrap-up

In this module you:

* Filled out ADO Preflight for your cluster.
* Ran *Bootstrap*, which generated a Git repository of playbooks, variables, and encrypted vault files and pushed it to Gitea.
* Ran those playbooks from the Preflight container to add a console banner and install the OpenShift Compliance Operator.

== Try it yourself

* *Run it again.* Click *Run selected playbooks* a second time. ADO's playbooks are safe to re-run; nothing changes on the cluster.
* *Remove the banner.* Set *Common extra vars* to `state=absent`, select only the `console` step, and run it. The banner is removed.
* *Change an answer.* Edit the banner text, run Bootstrap again, and look at the new commit in Gitea: the change is recorded in Git.
